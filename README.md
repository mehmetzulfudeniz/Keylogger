# Keylogger — Security Lab

> **Educational cybersecurity research only.** This repository is intended for controlled lab environments, defensive security learning, and understanding how keystroke-capture techniques can be detected and mitigated. Do not use it on systems, accounts, or devices without explicit authorization.

## Portfolio Context

This project is retained as part of an early cybersecurity learning portfolio. Its purpose is to study endpoint-security concepts such as input monitoring, behavioral indicators, permissions, detection strategies, and defensive controls.

## Security & Ethics

- Use only on systems you own or are explicitly authorized to test.
- Never collect real users' credentials, private communications, or personal data.
- Prefer isolated virtual machines and disposable lab environments.
- Treat any captured data as sensitive and remove it after testing.

## Defensive Learning Goals

- Understand how endpoint monitoring can be abused
- Recognize suspicious input-capture behavior
- Practice safe malware-analysis hygiene
- Learn why endpoint protection, least privilege, and application allowlisting matter

Legacy educational project. Not presented as production software.
